**PerkBridge Connect 1.4.0-rc.2** is the first published release candidate of PerkBridge Connect 1.4.0 (1.4.0-rc.1 was an internal build and was not published): a self-hosted platform that runs and supervises MetaTrader 5 terminals on your own Ubuntu servers, managed from one web dashboard. It collects every change since 1.3.0-rc.1.

**What's new in 1.4.0-rc.2:**

- **PerkBridge Chart (new app):** a trading app at `/chart/` on your Connect address, signed in with your Connect session. It has a price chart with an order ticket and prepared orders, and pages for *Layouts* (1, 2, 2×2, 3×3 or 4×4 charts), *Watchlist* (up to 50 accounts), *Orders* (all accounts, with bulk actions, an order timeline and a positions *Analytics* tab) and *Accounts* (statistics and per-trade MFE/MAE). Orders can be closed, edited, cancelled and modified from the chart. It uses the Connect API and your existing rights only.
- **PerkBridge Fleet Cockpit (new app):** an operations view at `/cockpit/` with *Incidents*, *Risk control* (read only), *Strategies* (library strategies, 24-hour P&L, pause/resume, deploy an update), *Brokers*, *Accounts* and *Audit*.
- **App menu:** after sign-in and in the top bar you choose between Connect, Chart and Fleet Cockpit, plus Identity management when PerkBridge Identity is set up.
- **Strategy library:** strategies come from library definitions and versions. A new version is rolled out with a preview and a digest, can be promoted, and merges the strategy's settings. Each library version records the `perkbridge-connect` version it uses.
- **Dry run:** `dry_run: true` in `strategy.yaml`, or the *Dry run* switch, runs a strategy without opening exposure.
- **Account risk limits in money or percent:** *Max risk per position* and *Max risk per account* (open risk), each in money or as a percent of the balance, enforced by the risk service when an order is admitted. The hidden lot limits per account and per route (*Largest order*, *Largest position per symbol*) are retired.
- **Recovery tab:** each deployment has a *Recovery* tab, with a red badge counting what needs a person: an open switch or restart and the orders it still owes an outcome for, unexplained deals to accept, and reconciliation differences to decide.
- **Trading resumes after maintenance:** after a host or runtime image maintenance, the Control Plane resumes a returned deployment on its own once the same checks as a person's *Resume trading* pass. Before, opening orders waited for a person and could expire as *Not sent in time*.
- **Economic calendar:** an official economic calendar service pulls the published sources every hour, with signed snapshots, sync alerts and its own tab under *Administration › Economic calendar*, for the news blackout rules.
- **Forming bar on request:** bars reads can include the bar that is still forming. This needs the runtime image NileTrade 1.9.0 (below); the Python strategy runtime pins `perkbridge-connect` 1.9.0b1.
- **Edit host limits:** an administrator can change a server's deployment limit from the server page.
- **Dashboard:** an order timeline chart in order details; library definition tabs and icon buttons; the runtime image card no longer offers a downgrade.
- **DirectConnect:** after a proxy restart, the restart fence is cleared on ledger and broker evidence and bounded by the proxy's last sign of life, and a person can accept the account's own unexplained deals. The DirectConnect risk policy is bound again after a placement change, and a fence restart no longer blocks a host agent update.
- **Runtime images:** the MetaTrader 5 runtime image moves to `main-35317cd7` (NileTrade 1.9.0), the default for new deployments in this release, and the Python strategy runtime to `3.12-main-35317cd7`. Both images are hardened (newer apt and zlib, fresh-layer builds). Approve the new images under *Servers › Images*, then update each deployment when no trade is in flight.

**Already installed 1.3.0-rc.1 or a beta?** Download and verify the 1.4.0-rc.2 bundle (below), then run `sudo nile-1.4.0-rc.2/nile-install upgrade --allowed-signers allowed_signers`, or run nile-setup 1.4.0-rc.2 from your computer. The upgrade takes a backup first, and upgrades the Control Plane before the agents. Then use *Run setup again* (or the host update) on each trading server so it gets the new agent and host components. This release adds database migrations 0132 to 0162; they only add tables, columns, indexes, constraints, functions and triggers, widen a constraint, or fill the new columns. Going back to 1.3.0-rc.1 or an earlier beta down to 1.0.5-beta is therefore a binary switch with `sudo nile-install rollback` and needs no database restore. For older releases, follow the install guide's rollback requirements; a rollback that needs the database backup requires `--rollback-restore`. A server whose agent has never reported blocks the upgrade; use `--exclude-host <server id>` only for a server you intend to exclude from the compatibility check.

## Install

There are two ways to install:

- **From your computer:** download the `nile-setup` file for your system, check it (below), and run it. It connects to your Ubuntu 24.04 server over SSH, downloads and verifies the bundle there, installs Docker if needed, and installs the Control Plane. It runs on macOS, Windows and Ubuntu.
- **On the server:** download `nile-1.4.0-rc.2-linux-amd64.tar.gz`, verify it, and run `sudo nile-1.4.0-rc.2/nile-install install --allowed-signers allowed_signers --license default`.

**Server requirements:** Ubuntu 24.04 LTS, 64-bit (amd64), with root access. Docker Engine is installed for you when it's missing.

## Verify before you run anything

Every file in this release is signed with the PerkBridge release key `perkbridge-release-1`. Take the key from [`allowed_signers`](https://github.com/perkbridge/connect-releases/blob/main/allowed_signers) in this repository, never from inside the bundle.

To check the desktop installers and checksums:

```sh
ssh-keygen -Y verify -f allowed_signers -I release@nile.perkbridge \
  -n setup@nile.perkbridge -s SHA256SUMS.sig < SHA256SUMS
sha256sum --ignore-missing -c SHA256SUMS      # macOS: shasum -a 256 --ignore-missing -c SHA256SUMS
```

To check the server bundle, after `tar -xzf nile-1.4.0-rc.2-linux-amd64.tar.gz`:

```sh
ssh-keygen -Y verify -f allowed_signers -I release@nile.perkbridge \
  -n install@nile.perkbridge -s nile-1.4.0-rc.2/install-manifest.json.sshsig \
  < nile-1.4.0-rc.2/install-manifest.json
nile-1.4.0-rc.2/nile-install verify --allowed-signers allowed_signers
```

Each `ssh-keygen` command must print `Good "…" signature for release@nile.perkbridge`. If it prints anything else, delete the download and stop.

The desktop installers aren't code-signed by Apple or Microsoft yet:

- **Windows:** SmartScreen asks first. Choose *More info*, then *Run anyway*.
- **macOS:** after the first launch, allow the app in *System Settings › Privacy & Security*.

## What's included

- **Servers:** connect your own Ubuntu servers over SSH, with host-key confirmation and temporary credentials. A Fleet Agent, watchdog and credential vault are installed on each one, and its health and resource use are shown.
- **Deployments:** isolated MetaTrader 5 terminals in Docker under Wine, with start, stop, restart-after-reboot, memory limits, and a guided create flow that picks the platform version first.
- **Failover:** a hot standby on a second server, armed from the dashboard and promoted under documented safety rules that prevent duplicate trading.
- **Credentials:** broker passwords stay in the split-key vault on the trading server. The Control Plane never stores them in clear.
- **Trading:** accounts, orders, risk rules (limits, time windows, news blackout) and an emergency stop. Closing positions and cancelling orders always stays possible, even during a halt.
- **Trading API:** a REST API with API tokens.
- **DirectConnect (opt-in):** a low-latency order path for demo accounts, with proxies deployed from the dashboard. Needs the `directconnect` licence feature.
- **PerkBridge Chart and Fleet Cockpit:** a trading app and an operations view, on the same address and sign-in as Connect.
- **Monitoring:** events, alerts and deployment health, with alerts delivered to Telegram, Slack, email or a signed webhook.
- **PerkBridge Identity (optional):** single sign-on, with users, groups and roles.
- **Platform updates:** agent and host component updates delivered from the dashboard, signed and verified on each server.
- **Licensing:** the bundle carries a signed default licence for 1 server, 2 deployments and 1 notification channel, valid until 2027-10-29. Without a licence, a new installation runs the same starter allowance. Larger licences are issued by PerkBridge.

MetaTrader 5 itself isn't included. The terminal is downloaded from MetaQuotes on your server.

## Known limitations

- Order limits count only orders sent through Connect. Orders placed directly in the terminal or by another Connect installation aren't included.
- Trading servers must run Ubuntu 24.04 on amd64. Windows servers are planned.
- Newer MetaTrader 5 builds detect Wine's debugger layer on some versions. The runtime uses Wine 11.20; tell us if a terminal build refuses to start.
- MT5 history needs a running terminal and an updated Fleet Agent. Reads can take up to 30 seconds; temporarily unavailable history returns an error. Broker position-ID assumptions and netting-reversal handling have not yet been verified against a real terminal.
- DirectConnect has not yet been run against a real MetaTrader 5 terminal and broker. After a failover promotes a hot standby in place, DirectConnect stays closed until the deployment is re-created; use demo accounts only. It needs the `directconnect` licence feature, and only the File-channel image is published.
- If the Control Plane's own server is also a trading server and you roll back to an older release, that release sets `/var/lib/nile` back to mode 0700 and the credential vault on that server stops again until you upgrade.
- The desktop installers aren't notarized by Apple or signed by Microsoft (see above).
- There's no self-service licence portal yet. Contact PerkBridge for a larger licence.
- Back up before upgrading. Rollback to 1.1.9-beta, 1.1.8-beta, 1.1.7-beta, 1.1.6-beta, 1.1.5-beta, 1.1.4-beta, 1.1.3-beta, 1.1.2-beta, 1.1.1-beta, 1.1.0-beta or 1.0.5-beta does not require a database restore; for older releases, follow the install guide and use `--rollback-restore` when required.
