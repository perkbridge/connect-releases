**PerkBridge Connect 1.2.1-beta** is a beta of PerkBridge Connect: a self-hosted platform that runs and supervises MetaTrader 5 terminals on your own Ubuntu servers, managed from one web dashboard.

**What's new in 1.2.1-beta (since 1.2.0-beta):**

- **Strategies in the default licence:** the licence included in the bundle now allows up to 2 Python strategies. Its other limits are unchanged: 1 server, 2 deployments, 1 notification channel.
- **Stages and account responsibility (ADR-055):** the demo-only checks are withdrawn, so a deployment can trade a demo or a live account. An account's type is shown from its `account` tag, and linked resources must share the same `stage` tag (for example demo or live). Both tag keys are suggested under *Settings › Tags*.
- **Routes:** symbol chips, and strategy accounts can trade through a route.
- **Dashboard:** a server *Installation* tab, *Run setup again* under *Updates*, a redesigned position protection panel, a compact parameters table in the strategy editor, search and pages of 20 for account choosers, Trading accounts and Routes, and a confirmation before a `strategy.yaml` is applied.
- **nile-setup:** can create the server on a cloud provider, Scaleway first (ADR-056).
- **Fixes:** returns of a confirmed stop no longer get stuck; the protection toggle handles an edge case.
- **Security:** Go 1.26.11 (net/http fix GO-2026-6859), updated libraries and container images (PostgreSQL, Caddy, Keycloak).
- **Runtime images:** the MetaTrader 5 runtime images move to `main-bb07f81` (NileTrade 1.4.0, which no longer refuses live accounts). Approve the new image under *Servers › Images*. Check the stage tags before you bind a live account.

**Already installed an earlier beta?** Download and verify the 1.2.1-beta bundle (below), then run `sudo nile-1.2.1-beta/nile-install upgrade --allowed-signers allowed_signers`, or run nile-setup 1.2.1-beta from your computer. The upgrade takes a backup first. Then use *Run setup again* (or the host update) on each trading server so it gets the new agent and host components. This release adds one database migration, which only adds tag definitions and a trigger. Going back to 1.2.0-beta, 1.1.10-beta, 1.1.9-beta, 1.1.8-beta, 1.1.7-beta, 1.1.6-beta, 1.1.5-beta, 1.1.4-beta, 1.1.3-beta, 1.1.2-beta, 1.1.1-beta, 1.1.0-beta or 1.0.5-beta is therefore still a binary switch with `sudo nile-install rollback` and needs no database restore. An installation that already applied a licence keeps it; the new default licence applies to new installs with `--license default`. For older releases, follow the install guide's rollback requirements; a rollback that needs the database backup requires `--rollback-restore`. A server whose agent has never reported blocks the upgrade; use `--exclude-host <server id>` only for a server you intend to exclude from the compatibility check.

> **Beta.** Use demo broker accounts or small risk while you evaluate it. Deleting a deployment never closes broker positions; close them from the dashboard or the terminal first.

## Install

There are two ways to install:

- **From your computer:** download the `nile-setup` file for your system, check it (below), and run it. It connects to your Ubuntu 24.04 server over SSH, downloads and verifies the bundle there, installs Docker if needed, and installs the Control Plane. It runs on macOS, Windows and Ubuntu.
- **On the server:** download `nile-1.2.1-beta-linux-amd64.tar.gz`, verify it, and run `sudo nile-1.2.1-beta/nile-install install --allowed-signers allowed_signers --license default`.

**Server requirements:** Ubuntu 24.04 LTS, 64-bit (amd64), with root access. Docker Engine is installed for you when it's missing.

## Verify before you run anything

Every file in this release is signed with the PerkBridge release key `perkbridge-release-1`. Take the key from [`allowed_signers`](https://github.com/perkbridge/connect-releases/blob/main/allowed_signers) in this repository, never from inside the bundle.

To check the desktop installers and checksums:

```sh
ssh-keygen -Y verify -f allowed_signers -I release@nile.perkbridge \
  -n setup@nile.perkbridge -s SHA256SUMS.sig < SHA256SUMS
sha256sum --ignore-missing -c SHA256SUMS      # macOS: shasum -a 256 --ignore-missing -c SHA256SUMS
```

To check the server bundle, after `tar -xzf nile-1.2.1-beta-linux-amd64.tar.gz`:

```sh
ssh-keygen -Y verify -f allowed_signers -I release@nile.perkbridge \
  -n install@nile.perkbridge -s nile-1.2.1-beta/install-manifest.json.sshsig \
  < nile-1.2.1-beta/install-manifest.json
nile-1.2.1-beta/nile-install verify --allowed-signers allowed_signers
```

Each `ssh-keygen` command must print `Good "…" signature for release@nile.perkbridge`. If it prints anything else, delete the download and stop.

The desktop installers aren't code-signed by Apple or Microsoft yet:

- **Windows:** SmartScreen asks first. Choose *More info*, then *Run anyway*.
- **macOS:** after the first launch, allow the app in *System Settings › Privacy & Security*.

## What's included

- **Servers:** connect your own Ubuntu servers over SSH, with host-key confirmation and temporary credentials. A Fleet Agent, watchdog and credential vault are installed on each one, and its health and resource use are shown.
- **Deployments:** isolated MetaTrader 5 terminals in Docker under Wine, with start, stop, restart-after-reboot, memory limits, and a guided create flow that picks the platform version first.
- **Failover:** a hot standby on a second server, armed from the dashboard and promoted under documented safety rules that prevent duplicate trading.
- **Credentials:** broker passwords stay in the split-key vault on the trading server. The Control Plane never stores them in clear.
- **Trading:** accounts, orders, risk rules (limits, time windows, news blackout) and an emergency stop. Closing positions and cancelling orders always stays possible, even during a halt.
- **Trading API:** a REST API with API tokens.
- **DirectConnect (opt-in):** a low-latency order path for demo accounts, with proxies deployed from the dashboard. Needs the `directconnect` licence feature.
- **Monitoring:** events, alerts and deployment health, with alerts delivered to Telegram, Slack, email or a signed webhook.
- **PerkBridge Identity (optional):** single sign-on, with users, groups and roles.
- **Platform updates:** agent and host component updates delivered from the dashboard, signed and verified on each server.
- **Licensing:** the bundle carries a signed default licence for 1 server, 2 deployments and 1 notification channel, valid until 2027-10-29. Without a licence, a new installation runs the same starter allowance. Larger licences are issued by PerkBridge.

MetaTrader 5 itself isn't included. The terminal is downloaded from MetaQuotes on your server.

## Known limitations

- Order limits count only orders sent through Connect. Orders placed directly in the terminal or by another Connect installation aren't included.
- Trading servers must run Ubuntu 24.04 on amd64. Windows servers are planned.
- Newer MetaTrader 5 builds detect Wine's debugger layer on some versions. The runtime uses Wine 11.20; tell us if a terminal build refuses to start.
- MT5 history needs a running terminal and an updated Fleet Agent. Reads can take up to 30 seconds; temporarily unavailable history returns an error. Broker position-ID assumptions and netting-reversal handling have not yet been verified against a real terminal.
- DirectConnect has not yet been run against a real MetaTrader 5 terminal and broker. After a failover promotes a hot standby in place, DirectConnect stays closed until the deployment is re-created; use demo accounts only. It needs the `directconnect` licence feature, and only the File-channel image is published.
- If the Control Plane's own server is also a trading server and you roll back to an older release, that release sets `/var/lib/nile` back to mode 0700 and the credential vault on that server stops again until you upgrade.
- The desktop installers aren't notarized by Apple or signed by Microsoft (see above).
- There's no self-service licence portal yet. Contact PerkBridge for a larger licence.
- Back up before upgrading. Rollback to 1.1.9-beta, 1.1.8-beta, 1.1.7-beta, 1.1.6-beta, 1.1.5-beta, 1.1.4-beta, 1.1.3-beta, 1.1.2-beta, 1.1.1-beta, 1.1.0-beta or 1.0.5-beta does not require a database restore; for older releases, follow the install guide and use `--rollback-restore` when required.
